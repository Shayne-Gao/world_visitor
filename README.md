# Changelog - 世界迷雾 Web (Fog of World Web)

本项目旨在打造一个**完全本地优先 (Local-First)**、可终生记录并运行 30 年的个人地理空间数字资产系统。

---

## [v0.1.11] - 2026-03-25
### 🚀 Features (新功能)
* **标记模式专属地点搜索**：在“标记模式”下新增顶部搜索框，接入 OpenStreetMap Nominatim 免费 API。支持输入全球地名（如“武汉”），回车后平滑飞跃定位至目标区域，极大提升了跨地域历史足迹的补录效率。

---

## [v0.1.10] - 2026-03-25
### 🎨 UI/UX (视觉与交互体验)
* **底部主操作控件重构**：
  * **形态瘦身**：将原本沉重的深蓝色长条按钮进化为“悬浮药丸”式现代设计。通过缩小内边距和字体，显著降低了视觉侵入感。
  * **文案精简**：废除冗长的 `浏览模式 ➔ 点击标记` 指引，改为直观的功能导向文案 `开始标记` 与 `完成标记`。
  * **动效增强**：引入平滑的 `transition` 过渡动画、悬浮升起 (`hover`) 与按下反馈 (`active`)，提升了点击的物理实感。
  * **配色逻辑优化**：默认状态采用“白底蓝标”的高亮清爽色系，仅在“标记模式”下切换为警示红，色彩语义更加明确。

---

## [v0.1.9] - 2026-03-20
### 🎨 UI/UX (视觉与交互体验)
* **全局高空视效重构**：优化地图缩放至全球视角时的视觉补偿，探索区域由“突兀的彩色实线”改为“纯白色、透明度 `0.35` 的柔和薄雾”，完美模拟高空俯视云层散开的真实物理质感。
* **行政区面板排版优化**：移除探索档案面板的强制单行截断限制，超长行政区地名（如 *Singapore River Planning Area*）现支持自动折行并自适应高度对齐显示。

## [v0.1.8] - 2026-03-20
### 🗜️ Performance & Data (极限瘦身与性能)
* **GZIP 二进制流压缩**：引入浏览器原生 `CompressionStream` API，导出文件由纯文本 JSON 升级为极速高压的二进制 `.fogbak` / `.gz` 格式，文件体积骤降 **80%~90%**。
* **拓扑数据按需剔除**：导出时自动剥离冗余的巨大黑块 `globalFog` 数据（由数十万个多边形顶点组成）。在跨设备导入时，利用底座绿地数据执行零延时反向重算补全迷雾，彻底解决存档体积膨胀问题。

## [v0.1.7] - 2026-03-20
### 🐛 Bug Fixes & Refactor
* **OSM 层级修正**：修复 OpenStreetMap 逆地理编码层级粒度问题，将嗅探精度从 `[3, 10, 14]` 修正为容错率更高的 `[3 (国家), 7 (城市), 10 (区/县)]`。
* **UI 修复**：将缺失的“探索总面积 (km²)”指标重新补充至探索面板顶部。

## [v0.1.6] - 2026-03-20
### 🚀 Features (新功能)
* **多级区域并发计算**：成就系统升级，单次定位或绘图即可并发获取当前所在的 **国家、城市、街区** 三个层级的多边形边界，并独立计算各层级的探索进度。
### 🎨 UI/UX (视觉与交互体验)
* **高级拟物风面板**：数据面板升级为 Dark Glassmorphism（暗黑毛玻璃）材质，配合高反差荧光马卡龙色系（绿、蓝、紫、黄）的等宽字体（Monospace）。
* **面板折叠收纳**：新增面板交互开关，支持平滑折叠/展开，释放地图可视区域。

## [v0.1.5] - 2026-03-20
### 🚀 Features (新功能)
* **全自动行政区嗅探 (Auto-sniffing)**：接入 OpenStreetMap Nominatim 免费 API。后台根据经纬度静默执行逆地理编码 (Reverse Geocoding)，动态提取当前城市的闭合多边形 GeoJSON。
* **本地边界库 (Regions Cache)**：获取到的政府级版图数据自动永久缓存至本地 IndexedDB，实现断网可用与数据私有化。
### 🛡️ Robustness (健壮性)
* **防风控与节流设计**：加入 `1100ms` 并发请求保护与 `6000ms` 全局防抖，避免高频请求被免费 API 官方拉黑。

## [v0.1.4] - 2026-03-20
### 🏗️ Architecture (底层架构史诗级重构)
* **CQRS 终极数据模型**：重构底层数据结构，引入双轨制存储方案：
  * **本源数据 (`sourceOfTruth`)**：绝对安全的原生轨迹库，只进不出，永久保存原始点位（经纬度坐标、时间戳、画笔粗细）。
  * **渲染缓存 (`renderCache`)**：按天及全局合并的增量多边形缓存，专供前端“秒开”渲染。
* **Google Polyline 算法**：手动集成谷歌地图底层的折线编码算法，将原生坐标集压缩为极短的 ASCII 字符串，大幅降低本地存储压力。
### 🚀 Features (新功能)
* **人生进度条 (Stats HUD)**：利用 Turf.js 面积积分算法，实时计算并展示以平方公里 (`km²`) 为单位的总探索面积，及点亮地球的百分比。
* **无缝向下兼容**：内置数据迁移脚本，可完美识别并无损升级 `v3/v4` 版本的旧格式存档。

## [v0.1.3] - 2026-03-20
### 🎨 UI/UX (视觉与交互体验)
* **专业级 GIS 交互模式**：
  * 彻底解耦 PC 端与移动端的事件系统，干掉浏览器默认右键菜单 (`contextmenu`)。
  * 确立 **“左键专属画图，右键专属拖拽平移”** 的 PC 端硬核操作逻辑。
  * 修复了之前原生鼠标事件与 Leaflet 内置拖拽事件冲突的问题。

## [v0.1.2] - 2026-03-20
### 🎨 UI/UX (视觉与交互体验)
* **全局视觉补偿 (Pixel Compensation)**：解决地图缩小至全球视野时探索轨迹“隐形”的物理问题。动态引入按屏幕绝对像素计算的补全线宽 (`compWeight`)，保证微小足迹在全世界维度下依然清晰可见。

## [v0.1.1] - 2026-03-20
### 🎨 UI/UX (视觉与交互体验)
* **时光机 UI 收纳**：将占用底部空间的时光机滑块移至右侧悬浮栏，改为点击图标后从右向左平滑弹出的交互模式。

## [v0.1.0] - 2026-03-19
### 🏗️ Architecture (存储引擎换代)
* **告别 LocalStorage**：全面废弃容量极小（通常限制 5MB）且同步阻塞的 LocalStorage，引入工业级库 `localforage`。
* **异步数据库基座**：底层无缝切换为异步非阻塞、容量无上限的 `IndexedDB` 引擎，彻底根除高频绘图时 `JSON.stringify` 导致的 UI 卡顿、掉帧问题。
* **Storage Adapter 适配层**：封装统一的异步 `DataManager`，为未来迁移至 VPS (Node.js/Python 后端) 铺平道路。
### 🚀 Features (新功能)
* **跨设备存档流转**：实装基于 `Blob` 的全量存档导入与导出功能，实现手机与 PC 间的文件流转同步。

## [v0.0.9] 及更早版本 (MVP 概念验证期)
### 🚀 核心奠基
* **引擎选型**：确立以 `Leaflet.js` 为渲染底座（卫星图/街道图无缝切换），以 `Turf.js` 为空间几何运算核心。
* **迷雾消除逻辑**：实现核心的 `turf.difference`（全局迷雾挖洞）与 `turf.union`（足迹融合）布尔运算。
* **实时定位打卡**：接入浏览器原生 `Geolocation API`，支持基于当前 GPS 坐标的实时点亮。
* **基础交互**：实装多档位画笔 (`0.02km / 0.05km / 0.1km`)，支持单指划线、撤销操作。
* **历史回溯系统**：引入按天记录的“时光机”滑块，可回放过往的解锁足迹。
* **极限数据瘦身**：在 LocalStorage 时期，采用 `turf.simplify` (抽稀) 和 `turf.truncate` (截断小数位) 的极限容灾策略，防止存储过早溢出。
