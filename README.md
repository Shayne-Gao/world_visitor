# Changelog - 世界迷雾 Web (Fog of World Web)

本项目旨在打造一个**完全本地优先 (Local-First)**、可终生记录并运行 30 年的个人地理空间数字资产系统。

---

## [v0.1.18] - 2026-04-03
### 🎨 UI/UX (视觉与交互体验)
* **追踪模式地图全亮**：在“自动追踪”模式下，为了让用户更清晰地认路，系统会自动隐藏所有迷雾 (`globalFog`) 和已探索区域 (`globalExplored`)。此时地图全亮，仅展示绿色的实时运动轨迹草稿与蓝色脉冲当前坐标。
* **追踪模式实时状态灯**：自动追踪开启后，普通地图界面的左上角（档案面板下方）会悬浮显示一个带有呼吸动画的 GPS 状态指示灯（绿/红）及当前定位精度。
* **省电模式入口文案优化**：将追踪模式底部的省电入口按钮宽度微调，并追加了“息屏”二字，整体 UI 风格更加协调且表意明确。
* **极客排版与布局优化**：
  * **防误触组件上移**：将 OLED 省电模式底部的“滑动解锁”组件向上方提升了一定距离，完美避开移动端底部安全区与浏览器导航 Bar，操作更加顺滑。
  * **Geek 字体**：省电模式全面引入硬核等宽字体族（`SF Mono, Menlo, Monaco, Consolas`），字体变大且加粗，数字跳动更加整齐，极客感拉满。

## [v0.1.16] - 2026-04-03
### 🚀 Features (新功能)
* **OLED 极客省电模式 (Pocket Mode)**：
  * **极限续航**：专为长时间户外自动追踪设计。进入该模式后，系统将彻底掐断 Leaflet 引擎的 GPU 渲染、网络切片请求与 DOM 重绘，配合 OLED 屏幕纯黑不发光的物理特性，将电池消耗降至最低。
  * **极简信息面板**：在纯黑背景下，仅以暗绿色等宽字体提供最核心的探索距离（km）、当前时间以及 GPS 状态呼吸灯。
  * **Canvas 轻量轨迹渲染**：摒弃沉重的地图底图与 Turf.js 空间运算，利用基础 Canvas 2D API 将实时坐标按比例映射为极简线条，提供最直观的相对位置反馈。
  * **iOS 级防误触解锁**：引入经典的“滑动解锁 (Slide to Unlock)”组件退出该模式，彻底杜绝手机放在口袋中摩擦产生的误触中断。
  * **幽灵草稿箱**：省电模式下，底层 GPS 监听依然坚如磐石。轨迹数据被静默写入 IndexedDB 的幽灵草稿箱（`DRAFT_KEY`）中，确保即使发生浏览器崩溃也能在下次启动时无损恢复。

## [v0.1.15] - 2026-04-01
### 🐛 Bug Fixes & Stability (稳定性修复)
* **自动追踪“防飞线”机制 (Anti-Flying-Line)**：彻底修复了移动端锁屏、切后台导致 GPS 中断后，重新唤醒时与上一个坐标连成穿墙长直线（飞线）的致命 Bug。
  * **机制原理**：当系统检测到两个连续坐标点之间的距离突变 `> 200米` 时，会自动判定为“断线”。此时系统会静默结算（保存）中断前的上一段轨迹，并将当前的新坐标作为一段全新轨迹的起点。
  * **效果**：保证了真实足迹的绝对可靠性，宁可留白也绝不瞎连直线。

### 🎨 UI/UX & Interaction (交互与体验全面升级)
* **地图底图重构**：
  * **引入 Google Maps 源**：新增 Google 混合地图（Satellite + Labels）与 Google 街道图，并**将默认底图更改为 Google 混合模式**，大幅提升城市区域的探索体验。
  * **图层二级菜单**：移除拥挤的独立切换按钮，重构为优雅的毛玻璃二级菜单，内含 5 种图层源一键切换。
* **底部主控台整合 (Split Button)**：将“自动追踪”与“手动标记”合并为统一的 3/7 比例分割按钮，点击任意模式后自动合并为红色的“结束操作”按钮，收敛全局状态出口。
* **沉浸式续档体验**：**移除打开网页时强制定位当前位置的逻辑**。系统现在会在启动时自动读取最后一次探索的坐标，并将地图完美停留在“上次离开的地方”。
* **极致移动端防误触**：
  * 引入 **60ms 触摸意图判定机制**。彻底解决在移动端编辑模式下，双指缩放/平移地图瞬间会误画一个绿点的问题。
  * 移动端进入编辑模式时，左上角的档案面板会自动**缩骨功化为一个小地球 Icon**，避免遮挡顶部的搜索框。
* **PC 端左键解放**：在默认浏览模式下，**彻底解锁左键拖拽地图功能**（不再局限于右键），更加符合大众直觉。标记模式下依然保持左键画笔、右键拖拽的专业逻辑。
* **视觉对齐**：将底部主控按钮向上平移至与时间轴同高，完美避开移动端浏览器底栏的遮挡。

## [v0.1.13] - 2026-03-26
### 🏗️ Architecture (底层架构升级)
* **数据结构 v2.0.0 正式发布**：
  * **空间索引 (BBox)**：为每一条轨迹 (Track) 引入了最小外接矩形 (Bounding Box) 存储。这为未来 30 年海量数据下的“区域极速检索”和“按需加载”奠定了坚实的性能地基。
  * **轨迹来源语义化**：细化了 `source` 字段，现在能准确区分 `web_draw` (手动)、`auto_track` (自动记录) 和 `auto_track_recovered` (崩溃恢复) 等来源。
  * **无缝迁移**：内置静默迁移逻辑。老用户在打开页面或导入旧存档时，系统会自动解压轨迹、重算 BBox 并平滑升级至 v2 格式。
* **版本标识更新**：UI 界面增加 `Schema v2.0` 标识，确保数据标准的透明性。

## [v0.1.12] - 2026-03-26
### 🚀 Features (新功能)
* **智能存档合并 (Smart Merge) 优化**：
  * **数据完整性保障**：修复了之前版本中过度压缩导致的时光机（Timeline）足迹丢失问题。现在合并时会保留所有唯一的历史轨迹。
  * **精准去重**：采用 ID + 路径指纹的双重去重机制，确保合并后的存档既不包含重复记录，又不会丢失任何一天的历史信息。
  * **高性能处理**：优化了大规模轨迹合并时的空间运算逻辑，加入坐标精度截断处理，防止几何图形在多次合并后产生畸变。
  * **导出瘦身**：继续保持导出时剔除冗余渲染缓存（Fog Cache）的策略，使存档文件保持在极小体积（KB 级），同时保证导入后能 100% 还原迷雾。

## [v0.1.4] - 2026-03-20
### 🏗️ Architecture (底层架构史诗级重构)
* **CQRS 终极数据模型**：重构底层数据结构，引入双轨制存储方案：
  * **本源数据 (`sourceOfTruth`)**：绝对安全的原生轨迹库，只进不出，永久保存原始点位（经纬度坐标、时间戳、画笔粗细）。
  * **渲染缓存 (`renderCache`)**：按天及全局合并的增量多边形缓存，专供前端“秒开”渲染。
* **Google Polyline 算法**：手动集成谷歌地图底层的折线编码算法，将原生坐标集压缩为极短的 ASCII 字符串，大幅降低本地存储压力。
### 🚀 Features (新功能)
* **人生进度条 (Stats HUD)**：利用 Turf.js 面积积分算法，实时计算并展示以平方公里 (`km²`) 为单位的总探索面积，及点亮地球的百分比。
* **无缝向下兼容**：内置数据迁移脚本，可完美识别并无损升级 `v3/v4` 版本的旧格式存档。

## [v0.0.9] 及更早版本 (MVP 概念验证期)
### 🚀 核心奠基
* **引擎选型**：确立以 `Leaflet.js` 为渲染底座（卫星图/街道图无缝切换），以 `Turf.js` 为空间几何运算核心。
* **迷雾消除逻辑**：实现核心的 `turf.difference`（全局迷雾挖洞）与 `turf.union`（足迹融合）布尔运算。
* **实时定位打卡**：接入浏览器原生 `Geolocation API`，支持基于当前 GPS 坐标的实时点亮。
* **基础交互**：实装多档位画笔 (`0.02km / 0.05km / 0.1km`)，支持单指划线、撤销操作。
* **历史回溯系统**：引入按天记录的“时光机”滑块，可回放过往的解锁足迹。
* **极限数据瘦身**：在 LocalStorage 时期，采用 `turf.simplify` (抽稀) 和 `turf.truncate` (截断小数位) 的极限容灾策略，防止存储过早溢出。
